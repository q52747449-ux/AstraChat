# AstraChat
تطبيق محادثة فوري (Web App) مبني باستخدام تكنولوجيات الويب الأساسية (HTML5, CSS3) ومتوافق بالكامل مع أنظمة الهواتف الذكية (Responsive Design). يعتمد التطبيق على قاعدة بيانات Firebase لإدارة المستخدمين والمحادثات الحية، ويوفر واجهة مستخدم معززة بأيقونات FontAwesome ومكتبات التأثيرات البصرية المتطورة.
